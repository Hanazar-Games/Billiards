# Cópia congelada das regras legadas (D046)

Estes 4 arquivos são uma cópia de [Hanazar-Games/Billiards](https://github.com/Hanazar-Games/Billiards) v1.26.13 (commit `0448b03`, licença MIT, ver `LICENSE` na raiz do repositório). Eles têm os mesmos caminhos relativos de `src/` no jogo original, então as importações relativas entre eles continuam válidas.

São usados só pelos testes diferenciais de `packages/modes`, que comparam o 8-ball e o 9-ball portados com as regras de antes, em milhares de tacadas aleatórias.

**Nunca edite estes arquivos.** O `MANIFEST.json` guarda o SHA-256 de cada um (com CRLF trocado por LF), e `test/legacy-copy.test.ts` falha se algum mudar.
