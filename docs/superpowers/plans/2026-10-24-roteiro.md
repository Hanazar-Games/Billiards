# Billiards Online — Roteiro de planos

**Spec:** [`docs/superpowers/specs/2026-10-24-billiards-online-design.md`](../specs/2026-10-24-billiards-online-design.md)

A spec cobre vários subsistemas, então cada fase recebe um **plano detalhado próprio**, escrito no início da fase. O motivo: cada plano depende do resultado da fase anterior (a F0 decide onde a física roda; a F1 define a API real de `packages/sim`). Este roteiro fixa a ordem, as dependências e o critério de saída de cada fase. Os critérios também aparecem em [`harness/feature_list.json`](../../../harness/feature_list.json), onde cada item só é marcado `"passes": true` depois de verificado.

## Regras do roteiro

- Uma fase só começa quando a anterior cumpre o critério de saída. Exceção: F3 pode correr em paralelo com F2.
- Antes de cada fase, o plano detalhado é escrito com a skill `superpowers:writing-plans`, revisado pelo usuário e salvo em `docs/superpowers/plans/`.
- Decisões novas ou alteradas entram em `harness/decisions.json`; o andamento entra em `harness/progress.md`.
